# 500 идей, которые можно реализовать

Банк из **500 идей** для пет-проектов, портфолио и практики — по 50 в каждом из 10 направлений.
У каждой идеи есть описание и оценка объёма: `S` — до вечера, `M` — 2–5 дней, `L` — 1–3 недели.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Интерактивный каталог: поиск, фильтры по направлению и сложности, сортировка, избранное (localStorage), кнопка «случайная идея». Один файл, работает офлайн. |
| `IDEAS.md` | Все 500 идей обычным списком — удобно читать и копировать. |
| `ideas.csv` | Та же база в таблице (Excel / Google Sheets). |
| `ideas/*.json` | Исходники по направлениям — правь здесь. |
| `ideas/_template.html` | Шаблон каталога. |
| `build.py` | Сборка `index.html` + `ideas.csv` + `IDEAS.md` из JSON. |

## Как пользоваться

```bash
python3 -m http.server 8000      # открыть http://localhost:8000
python3 build.py                 # пересобрать каталог после правки ideas/*.json
```

Добавить идею — дописать строку `["Название", "Описание", "S|M|L"]` в нужный файл
`ideas/*.json` и запустить `build.py` (скрипт проверит, что идей ровно 500 и нет дублей).

## Как выбрать, что делать

1. Нажми «🎲 Случайная идея» и попробуй сделать то, что выпало.
2. Фильтр `S` + избранное — список задач на вечер.
3. Начни с одной идеи, доведи до рабочего состояния и задеплой — важнее закончить, чем выбрать «идеальную».
