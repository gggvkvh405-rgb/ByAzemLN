# ByAzen

Игровой лаунчер с интерфейсом по референсу. Обложки взяты из референса, а показатели раздачи на баннере — данные макета.

## Windows x64

На Windows с Node.js 22 выполните:

```sh
npm ci
npm test
npm run build:win
```

Портативный `ByAzen-1.1.0-x64.exe` появится в `dist/`. Для запуска из исходников используйте `npm start`. После отправки изменений в GitHub workflow **Build ByAzen for Windows** соберёт тот же файл и приложит его к запуску в **Actions → Artifacts → ByAzen-Windows-x64**. Сборка не подписана.

## Как пользоваться

1. В **Sources → Hydra sources** вставьте URL JSON и нажмите **Preview URL** или выберите **Open JSON file**. Проверьте список и нажмите **Import source**. Приложение ожидает `downloads` с полями `title` и `uris`. Источники не предустановлены. URL можно обновить по одному или все сразу; при ошибке остаётся предыдущий снимок. Источник можно временно отключить или поднять выше в результатах поиска.
2. Найдите импортированную игру через **Catalogue** или глобальный поиск, откройте **Details** и выберите ссылку. HTTP(S)-файлы скачиваются по одному из очереди в **Downloads**. Можно поставить активную загрузку на паузу, возобновить её при поддержке сервером, отменить или повторить неудачную загрузку. Очередь действует только до закрытия лаунчера. Magnet-ссылки передаются установленному торрент-клиенту Windows.
3. После установки игры нажмите **Choose .exe**, выберите исполняемый файл и нажмите **Play**. Кнопка **Open folder** открывает папку привязанной игры в Проводнике. Лаунчер не распаковывает архивы и не запускает загруженные программы автоматически. Используйте только доверенные источники и файлы.

В **Sources** также можно искать по имени, домену и тегам, переименовывать источники и менять тайм-аут. **Export URLs** сохраняет текстовый список; вставьте этот список в **Import multiple URLs**, чтобы восстановить источники с предпросмотром. За один раз можно обработать до 20 URL.

## Личная библиотека

В **Library → Add game** можно создать свою запись. В её карточке доступны **Rename**, **Add favorite**, а в настольной версии — выбор `.exe` и **Play**. В библиотеке можно переключаться между плиткой и таблицей, смотреть избранное и недавние запуски. Записи и настройки вида сохраняются локально. Создайте подборку через **New collection** и добавьте в неё игры через кнопку **Collections** в карточке.

В **Launch profiles** можно сохранить несколько наборов аргументов для одного EXE. Вводите по одному аргументу на строку, включая значения с пробелами. **Run** запускает выбранный набор, **Make default** назначает его для обычной кнопки **Play**.

## Веб-превью

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Импорт Hydra JSON, скачивание с прогрессом и запуск `.exe` доступны только в настольной версии. В браузере можно просмотреть каталог и открыть вручную добавленные прямые ссылки.

## Резервные копии сохранений

В Windows-версии откройте карточку игры → **Save backups**, выберите папку сохранений и нажмите **Create backup**. ByAzen хранит несколько снимков, до 1 ГБ и 10 000 файлов на снимок. **Restore to new folder** распаковывает копию в новую папку внутри выбранной, не перезаписывая текущие сохранения. Копии не создаются автоматически.

## Каталог Steam

В разделе **Каталог → Магазин Steam** настольная версия получает страницы поиска непосредственно из магазина Steam. Доступны фильтры типа товара, жанра/метки, платформы, цены, сортировки и региона. Поиск по названию находится слева. Нажатие на карточку открывает официальную страницу товара; покупка и установка выполняются через Steam. Результаты, цены и доступность зависят от региона и ограничений магазина; снятые с продажи или скрытые Steam товары могут отсутствовать. Для каталога нужно подключение к Steam и интернету; изображения загружаются с CDN Steam. При ошибке используйте кнопку повторного запроса. Веб-превью не загружает Steam-каталог.

Вкладка **Мои источники** по-прежнему показывает локальные игры и все записи из включённых Hydra-источников. Источники можно импортировать и обновлять в разделе **Источники**; сторонние ссылки не предустановлены и не проверяются. Используйте только доверенные источники.
